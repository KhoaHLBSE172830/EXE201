# Thư mục lưu trữ code Prototype Figma cũ

Thư mục này chứa các file giao diện prototype đời đầu được xuất từ Figma:
- `MimoDashboard.jsx` & `MimoDashboard.css`: Chứa nhiều Icon SVG, Animation, Style màu của phân hệ Learner.
- `MimoLandingPage.jsx` & `MimoLandingPage.css`: Landing page mẫu ban đầu.
- `MimoRegisterPage.jsx` & `MimoRegisterPage.css`: Form đăng ký ban đầu.

> **Lưu ý:** Không xóa thư mục này. Khi code giao diện mới cho các phân hệ, bạn có thể copy lại các đoạn mã SVG, màu sắc và CSS từ đây sang.
