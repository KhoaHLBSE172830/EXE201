1. File: Mimo_EXE201_BE/Mimo.Application/Services/CurriculumService.cs
   - Lý do sửa: 
     Trong LINQ to Entities (IQueryable / Expression<Func<T, bool>>), Npgsql (PostgreSQL provider)
     KHÔNG THỂ dịch hàm string.Equals(..., StringComparison.OrdinalIgnoreCase) sang câu lệnh SQL
     WHERE clause. Khi client gọi GET /api/v1/domains hoặc GET /api/v1/path, hệ thống phát sinh
     ngoại lệ InvalidOperationException và trả về HTTP 500.
   - Các vị trí sửa:
     + Dòng 43 (GetDomainsAsync):
       [CŨ ]: d => string.Equals(d.Status, "Active", StringComparison.OrdinalIgnoreCase)
       [MỚI]: d => d.Status == "Active"

     + Dòng 51 (GetDomainsAsync - Published Nodes count):
       [CŨ ]: n => allUnitIds.Contains(n.UnitId) && string.Equals(n.Status, "Published", StringComparison.OrdinalIgnoreCase)
       [MỚI]: n => allUnitIds.Contains(n.UnitId) && n.Status == "Published"

     + Dòng 101 (GetDomainByIdAsync):
       [CŨ ]: n => unitIds.Contains(n.UnitId) && string.Equals(n.Status, "Published", StringComparison.OrdinalIgnoreCase)
       [MỚI]: n => unitIds.Contains(n.UnitId) && n.Status == "Published"

     + Dòng 150 (GetUnitByIdAsync):
       [CŨ ]: n => n.UnitId == unit.Id && string.Equals(n.Status, "Published", StringComparison.OrdinalIgnoreCase)
       [MỚI]: n => n.UnitId == unit.Id && n.Status == "Published"

     + Dòng 226 (GetLearningPathAsync):
       [CŨ ]: var activeDomains = await _domainRepository.WhereAsync(d => string.Equals(d.Status, "Active", StringComparison.OrdinalIgnoreCase));
       [MỚI]: var activeDomains = await _domainRepository.WhereAsync(d => d.Status == "Active");

     + Dòng 241 (GetLearningPathAsync - Lấy Published Nodes):
       [CŨ ]: n => unitIds.Contains(n.UnitId) && string.Equals(n.Status, "Published", StringComparison.OrdinalIgnoreCase)
       [MỚI]: n => unitIds.Contains(n.UnitId) && n.Status == "Published"

     + Dòng 375 (GetNodeDetailAsync):
       [CŨ ]: n => n.Id == nodeId && string.Equals(n.Status, "Published", StringComparison.OrdinalIgnoreCase)
       [MỚI]: n => n.Id == nodeId && n.Status == "Published"
